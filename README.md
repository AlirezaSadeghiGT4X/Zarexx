# 💰 Zarexx

A real-time gold, dollar, and currency price-tracking platform for Persian-speaking users — with a full RTL interface, Jalali calendar, and Persian numerals.

## ✨ Features

- 📊 Live prices for gold, dollar, euro, and cryptocurrencies
- 🇮🇷 Fully Persian, right-to-left (RTL) interface
- 📅 Jalali (Solar Hijri) calendar support
- 🔢 Persian numeral formatting
- 📈 Trending price indicators
